# Contributing

Contributions to code, tests, and documentation are welcome.
Please follow the [Code of Conduct](https://github.com/Pepps233/pocket-context/blob/main/.github/CODE_OF_CONDUCT.md).

## Issues and suggestions

Create a new issue for each issue or suggestion.
For issues, include a concrete description, steps to reproduce the issue, and screenshots if possible.
For suggestions, describe the proposed improvement and include screenshots if they help explain it.

## Pull requests

1. Fork the repository and create a branch for your changes.
2. Keep changes focused and add tests for new or changed behavior where appropriate.
3. Run relevant tests and `pre-commit run --all-files` before submitting.
4. Use the pull request template, explain the changes and validation, and link related issues.
5. Request @Pepps233 as a reviewer.

By contributing, you confirm that you have the right to submit your changes under the project's [MIT license](https://github.com/Pepps233/pocket-context/blob/main/LICENSE.md).
